# Rosebel Lopes — Consultoria Imobiliária | CRECI 205572

Website institucional e vitrine imobiliária para **Rosebel Lopes**, consultora imobiliária especializada no mercado de São Paulo (Vila Carrão, Jardim Anália Franco, Tatuapé, Mooca e Grande SP).

## 🚀 Tecnologias e Recursos

- **Animação de Scroll 3D (240 Frames Sequence)**: Renderização ultra-suave via HTML5 Canvas e interpolação a 60/120 FPS.
- **Inertial Smooth Scrolling**: Lenis Scroll integrado.
- **Micro-interações**: Efeito magnético de mouse follow 3D no Canvas e **Scroll Stack** na Vitrine de Imóveis (inspirado em *reactbits.dev*).
- **Simulador Interativo**: Calculadora dinâmica de Aluguel vs. Patrimônio Imobiliário.
- **Filtros Dinâmicos**: Vitrine de imóveis com filtragem em tempo real (Prontos, Lançamentos, Faixas de Preço).
- **Aceleração por Hardware (GPU)**: Zero motion blur e otimização `100dvh` para dispositivos móveis (iOS/Android).

## 💻 Como Rodar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/menochef777/rosebel-lopes.git
```
2. Inicie o servidor local:
```bash
node server.js
```
3. Acesse `http://localhost:3008/` no seu navegador.
